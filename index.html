The method Becker / Peter Olinto school + community-proven

Built from Becker's own guidance (Peter Olinto, JD, CPA — Becker's longtime national lead instructor), plus the habits that show up over and over from working candidates who passed (r/CPA, Another71, CPA TikTok/IG).
Questions are the curriculum — lectures are the preview. The Olinto-school core: you learn by doing MCQs and reading every explanation, not by rewatching lectures. Lectures once at 1.5–2x, working the examples by hand, then straight into that module's questions. Never rewatch; requestion.
Daily cumulative questions. The single most repeated Becker-veteran tip: a 20–40 question set from PAST units, regularly, so nothing decays. That's your Wednesday block — and the mobile sprint set on engagement days.
Do all the MCQs; SIMs at least once each. Community consensus for FAR. SIMs are 50% of your score — Saturdays, from week 1, not saved for the end.
Rework every miss. Start each session by redoing yesterday's wrong answers. Highest-yield 15 minutes that exists.
Don't chase perfection on first pass. 65–75% and move on. Cumulative sets and final review handle retention. Stalling on F2 while F7 waits is how working candidates run out of runway.
Working-candidate rhythm. What passers report: consistent short weekday blocks (not hero 4-hour nights), protected weekend mornings, study something every single day even if it's 20 phone MCQs, and sit the exam soon after review ends — momentum decays fast.
Hardest topics get extra reps: leases, bonds, income taxes, governmental, not-for-profit.

Discipline rules

Schedule the exam first. A paid-for date is the strongest forcing function. Book it this week.
Nothing before the block. No weed before or during study — it hits exactly the memory consolidation you're paying Becker for. After the block is checked off, or save it for Friday. Study first, always.
Never miss twice. Miss once, fine. Twice in a row is a decision. Friday is the makeup slot.
Phone in another room. Timer on, one tab open: Becker.
Show up tired. A bad 2-hour session beats a skipped one.
Check in daily and take the knowledge check. The streak is the habit; the quiz is the proof it stuck.

About this build

build
Updates deploy from GitHub automatically. If the version here looks behind after an update, fully close the app and reopen it — the offline cache serves the old copy once, then swaps.

Dates

Changing the start date re-anchors all 12 weeks, the Today tab, and every week's date range immediately. If the start is in the future, the dashboard runs in pre-season build mode — a prep checklist instead of study blocks — until day 1. Weeks run 7 days from whatever start day you pick (a Friday start means weeks run Fri→Thu; daily session types still follow the weekday).

Cloud sync & profile ready

Already connected to Cadence's cloud — nothing to configure. Pick an ID and password, hit Create account, and your progress follows you across every device. Anyone you share the app link with does the same; each person gets their own private profile.
Note: sign-in only works on the deployed app, not inside a preview window — previews block outside network calls.

Advanced · point at a different backend

Cadence ships pointed at its own Supabase project — you should not need to touch this. Only fill these in if you are self-hosting your own backend.

Your profile

Pick any ID and password. First time on a device: Create account. Already have one: Sign in with the same ID and password to pull your progress down. No email needed — but that also means there is no password reset, so use something you will remember.

Coach AI provider

Built-in Claude works automatically inside Cowork — no setup. To run the coach on a phone or standalone copy of this file, add your own API key: Anthropic (console.anthropic.com) or OpenAI (platform.openai.com). Note: these are pay-per-use developer keys, not your Claude Pro / ChatGPT Plus subscription — subscriptions can't be linked to outside apps. Coach messages cost fractions of a cent. Your key is stored only on this device. Inside Cowork's sandbox, outside API calls are blocked, so built-in Claude is always used there.

Effects

Backup / transfer

Data lives on this device only. Export here, then Import on your phone (or vice versa) to move your progress. Do this occasionally as a backup too.

Reset

Two levels. Soft reset clears the progress you earned and leaves your setup alone — API key, work schedule, dates and exam date all survive. Hard reset wipes the device clean, including your API key.
Soft clears: XP & rank, streak, hours logged, all checked tasks/objectives/daily steps, scores & quiz history, weak areas, coach log.  Soft keeps: API key & provider, work week & day types, exceptions, plan start & exam date, sound setting, custom unit names.
